# Come Contribuire a WP Vet Plugin

Grazie per il tuo interesse nel contribuire a questo progetto! Ogni contributo, grande o piccolo, è molto apprezzato.

## Tipi di Contributi

- **Segnalare Bug:** Se trovi un errore, apri una issue dettagliata descrivendo il problema, i passaggi per riprodurlo e l'ambiente che stai usando.
- **Suggerire Miglioramenti:** Hai un'idea per una nuova funzionalità o un miglioramento? Apri una issue per discuterne.
- **Scrivere Codice:** Se vuoi correggere un bug o implementare una nuova funzionalità, sentiti libero di inviare una pull request.
- **Migliorare la Documentazione:** Se noti errori o mancanze nella documentazione, puoi proporre delle modifiche.

## Linee Guida per le Pull Request

1.  **Forka il Repository:** Crea una tua copia del progetto.
2.  **Crea un Nuovo Branch:** Lavora su un branch separato per la tua modifica (es. `feature/nuova-funzionalita` o `fix/correzione-bug`).
3.  **Scrivi Codice Chiaro:** Assicurati che il tuo codice sia leggibile e ben commentato, se necessario.
4.  **Mantieni la Coerenza:** Cerca di seguire lo stile di codifica esistente.
5.  **Invia la Pull Request:** Descrivi chiaramente le modifiche che hai apportato e perché sono necessarie.

Grazie ancora per il tuo contributo!
