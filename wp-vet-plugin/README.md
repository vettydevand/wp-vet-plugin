# WP Vet Plugin

This plugin provides a calendar for managing veterinary appointments.

## Standalone Mode

This plugin can also be run in a standalone mode, without WordPress.

### Requirements

* PHP
* SQLite

### Setup

1.  Navigate to the `modern-standalone` directory.
2.  Make sure you have a web server with PHP and SQLite installed.
3.  Open the `index.html` file in your browser, served by your web server.

That's it! You can now use the calendar.
